# HealthCare-Survey-Form
A simple and responsive web-based healthcare survey form built with HTML and CSS.
It allows users to submit basic personal information, current symptoms, and pre-existing conditions. 
The form is designed for ease of use and accessibility in a healthcare or research setting.

## 🌐 Overview
The form collects the following data:
- First and Last Name
- Age and Gender
- Current symptoms (Fever, Cough, Fatigue, Shortness of Breath)
- Pre-existing conditions (Diabetes, Hypertension, Heart Disease)
- Additional comments or concerns

## ✨ Features

- ✅ Clean and modern user interface
- 📱 Fully responsive design
- 📝 Checkbox options for multiple selections
- 🎯 Drop-downs for gender and controlled inputs
- 📷 Background image integration for aesthetic design

## 🛠️ Technologies Used

- **HTML** – Structure of the form
- **CSS** – Styling and layout
- *(No JavaScript is used in this version)*
